VR STUDIO PERSONALIZADOS - SITE V2

NOVIDADES DESTA VERSÃO
- Página produtos.html
- Catálogo com busca e filtros
- Carrinho de cotação
- Controle de quantidades
- Campo de observações
- Botão que envia a seleção para o WhatsApp
- Carrinho salvo no navegador com localStorage
- Layout responsivo para celular e computador

ARQUIVOS
- index.html: página inicial
- produtos.html: catálogo e carrinho
- style.css: estilos gerais
- shared.js: menu, ano e contador compartilhado
- produtos.js: produtos, filtros, carrinho e WhatsApp
- assets/logo-vr-studio.png: logo

ATUALIZAR NO GITHUB
1. Extraia este ZIP.
2. Copie todo o conteúdo de vr_studio_site_v2.
3. Cole dentro da pasta local do repositório vr-studio-site.
4. Autorize a substituição dos arquivos existentes.
5. No GitHub Desktop, faça o commit.
6. Clique em Push origin.
7. O GitHub Pages atualizará o site automaticamente.
